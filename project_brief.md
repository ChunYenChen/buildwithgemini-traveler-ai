# My agent: Traveler AI
One-liner: A conversational agent that helps travelers plan and customize personalized travel itineraries with a catalog of destinations, attractions, and activities.

Tool coverage:
- Memory: User travel preferences (pacing, luxury vs budget, interests like nature/food/culture), dietary restrictions, and past visited places
- Tools: Weather lookup, destination/attraction search, daily itinerary planner, and estimated transit calculator
- Catalog/UI: Curated attraction cards, daily itinerary breakdown cards, and recommended dining/hotel comparison tables
- Image gen: Personalized dream travel postcards, landmark concept art, and itinerary header visuals
- Sandbox: Travel budget planning, currency exchange conversions, and group expense splitting

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for budget optimization and currency conversion; Google Maps API integration; Cloud Trace for observability
